# Appendix B — Evidence To Collect

The site now explains well; these are the assets that make it *prove*.
Each entry: asset → source → format → destination. Nothing ships without
permission and a real number.

## 1. Multi-location proof block (highest value)
- **Asset:** short case block — locations count, applicants assessed, one
  operational observation in the operator's own words.
- **Source:** the 5-location franchisee. `[CONFIRM: publicly nameable?
  quote permission? who asks — Yan?]`
- **Format:** 2–3 sentences + attribution line ("—Name, 5-location
  [brand] franchisee"). Optional: logo permission.
- **Destination:** /for-qsr after the "what changes" bullets; excerpt on
  homepage proof strip.

## 2. Homepage pull quote
- **Asset:** one-sentence operator quote + one number ("X applicants
  assessed, first shortlist the same day").
- **Source:** shopping-center cohort operator or the franchisee.
  `[CONFIRM: which operators may be referenced publicly?]`
- **Format:** pull quote, name, role, location count.
- **Destination:** homepage, between audience cards and founder block.

## 3. Assessment completion rate
- **Asset:** % of applicants who finish the assessment once started (and
  median completion time if it's ≤6 min).
- **Source:** production data — assessment_sessions started vs. completed,
  across all non-demo orgs. (Query, don't estimate; exclude demo org.)
- **Format:** single number, dated ("As of [month]: X% completion").
- **Destination:** /faq "Will asking people to take an assessment scare
  them off?" — replaces the "[PLACEHOLDER — PROOF: real completion rate]".

## 4. Time-to-shortlist
- **Asset:** median time from posting → first banded shortlist (or from
  application → scored result, which is near-instant and more honest).
- **Source:** production timestamps.
- **Format:** "Applicants are scored the moment they finish — most
  operators see their first banded shortlist within [X]."
- **Destination:** homepage step 3 caption or /how-it-works step 3 detail.

## 5. No-show / early-quit comparison (long game — do not rush)
- **Asset:** before/after comparison from one committed operator (e.g., 16
  Handles New City: no-call-no-shows or <30-day quits, two comparable
  quarters).
- **Source:** operator's own records + founder's store.
- **Format:** founder-voiced ("In my own store: …") to keep it honest and
  unaudited-but-owned. Never generalized ("operators see 40% fewer…").
- **Destination:** founder block extension on /about; referenced from
  homepage founder block if strong.

## 6. Dashboard screenshots (Priority 2 — production, not mockups)
- **Asset A:** candidate list, banded, with flags + text/schedule actions
  (homepage, after step 3).
- **Asset B:** single candidate report (how-it-works, between steps 3–4).
- **Source:** demo org ("Broadway Scoops") — scrubbed data, realistic
  volume. Check every visible string against Hard Constraint 1 before
  capture (no "fit," "recommended," "top pick" in UI copy — audit the
  actual product UI strings first; if the UI itself says "Strong fit,"
  that's a product copy change to schedule before screenshots).
- **Format:** annotated (≤3 callouts), light-mode, retina.
- **Destination:** per Priority-2 specs in 01-home.md and
  02-how-it-works.md.
